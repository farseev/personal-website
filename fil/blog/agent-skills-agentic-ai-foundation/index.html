Naging Vendor-Neutral ang Agent Skills: Bakit Dapat Itong Pansinin ng mga Marketer

Ibinigay ng Anthropic ang Agent Skills standard sa Agentic AI Foundation. Ang portable at nakasulat na know-how ang mismong kailangan ng mga marketing team mula sa mga AI agent.

Ang balita: Ibinigay ng Anthropic ang Agent Skills open standard sa Agentic AI Foundation sa ilalim ng Linux Foundation (22 Oktubre 2026)

Ni Prof. Aleks Farseev8 Nobyembre 20264 na minutong basa

Ang ilan sa pinakamahalagang balita sa AI ay mukhang nakakabagot sa unang tingin. Noong 22 Oktubre, sinabi ng Anthropic na ipapasa nito ang Agent Skills standard sa Agentic AI Foundation, isang katawan sa ilalim ng Linux Foundation. Walang bagong modelo, walang benchmark. Pero kung nagpapatakbo ka ng marketing gamit ang mga AI agent, ito ang uri ng pundasyong imprastraktura na nagpapasya kung mananatiling iyo ang iyong know-how.

Ano ang nangyari

Ayon sa post ng Anthropic, ang isang skill ay "isang folder na naglalaman ng SKILL.md file na nagtuturo sa isang agent ng isang partikular na gawain o domain, kasama ang anumang script o reference material na kailangan nito." Binuo ng Anthropic ang format habang ginagawa ang Claude Code, dahil madalas na kulang ang mga general-purpose agent sa procedural knowledge na kailangan ng mga totoong gawain sa negosyo. Inilunsad nito ang skills noong Oktubre 2025 at inilathala ang Agent Skills bilang open standard noong Disyembre 2025.

Malalaki ang mga numero ng adoption. Sinasabi ng Anthropic na mahigit 70 agent platform na ang nag-integrate ng Agent Skills, kabilang ang ChatGPT, Cursor, GitHub Copilot at VS Code, at na 1 milyong skill na ang nailathala at halos 280 milyon na ang na-install.

Ngayon, ang standard mismo, ang pangalan at logo nito, ang GitHub organisation at ang domain na agentskills.io ay mapupunta sa Agentic AI Foundation (AAIF), na co-founded ng Anthropic kasama ang Block at OpenAI at kung saan dati na nitong ibinigay ang Model Context Protocol. Pananatilihin ito ng mga engineer mula sa Anthropic, Google, OpenAI at iba pang kumpanya bilang mga indibidwal. Kasama sa iminungkahing roadmap ang mga versioned release, isang pormal na proseso ng panukala at security guidance para sa mga taong sumusulat at nag-i-install ng skills.

Bakit ito mahalaga

Bawat marketing team na kilala ko ay may parehong nakatagong asset: ang paraan nila ng paggawa ng mga bagay. Kung paano sila sumusulat ng brief. Kung aling mga kakumpitensya ang una nilang sinusuri. Kung ano ang ibig sabihin ng "on brand" para sa kliyenteng ito sa market na ito. Sa ngayon, karamihan dito ay nasa isip ng mga tao at sa mga slide deck na walang bumabasa.

Ang skill ay isang paraan upang isulat ang prosesong iyon para masundan ito ng isang agent. At ang isang vendor-neutral na standard ay nangangahulugang maaari mo itong isulat nang isang beses at asahang gagana ito sa mga tool na ginagamit ng iyong team. Iyan ang pagkakaiba ng pagbuo sa isang platform at pagbuo sa isang format. Mas tumatagal ang mga format kaysa sa mga platform.

May pangalawa at mas tahimik na benepisyo. Nababasa ang isang skill. Maaari mong buksan ang folder at makita kung ano ang iniutos sa agent. Sa larangang nagiging karaniwang dahilan na ang "ang AI ang nagpasya", ang isang plain-text na proseso ay maliit ngunit tunay na bahagi ng pananagutan.

Ang sinasabi ng aking pananaliksik

Sumulat ako sa Forbes tungkol sa hagdan mula prompting at fine-tuning hanggang RAG at mga AI agent sa marketing, at tungkol sa 18 aplikasyon ng mga AI agent sa marketing. Ang paulit-ulit kong binabalikan: mas madalas pumalya ang mga agent hindi dahil kulang sila sa talino kundi dahil kulang sila sa konteksto: ang partikular na data at ang partikular na proseso para sa trabaho.

Ginagawa itong kongkreto ng aming pinakabagong papel. Sa SOMIN: Agentic AI for Automating Professional Visibility and Countering Content Homogenization (SIGIR 2026), inilalarawan namin ang mga retrieval-augmented agent na tumutulong sa mga propesyonal na sumulat ng natatanging LinkedIn content. Ang pangunahing ideya ay dapat kumuha ang agent ng totoong context data bago ito sumulat, upang manatiling natatangi ang output nito sa halip na mauwi sa parehong generic na text na nililikha ng agent ng iba.

Ang skills ay ang procedural na kakambal ng retrieval. Ibinibigay ng retrieval sa agent ang mga katotohanan. Ibinibigay ng skill ang pamamaraan. Parehong lumalaban ang mga ito sa homogenisation, dahil pareho silang nagpapasok ng kung ano ang partikular sa iyo sa isang system na kung hindi ay babalik sa karaniwan ng internet. Kung ang bawat brand ay nagpapatakbo ng parehong agent na may parehong default na pag-uugali, magkakatunog ang bawat brand. Ang iyong skills ang kinaroroonan ng iyong pagkakaiba.

Ang dapat gawin ngayon ng mga marketing team

  • Isulat ang tatlong prosesong inuulit mo bawat linggo, gaya ng competitor check, campaign post-mortem o creative brief, bilang simpleng step-by-step na tagubilin na may mga halimbawa ng mahusay na output.
  • Ihiwalay ang mga bahaging partikular sa brand: tone of voice, mga ipinagbabawal na pahayag, legal disclaimer, pagkakaiba ng mga market. Ito ang mga bahaging nagpapaging iyo sa iyong output.
  • Lagyan ng version ang mga ito. Kapag nagbago ang isang proseso, nagbabago ang pag-uugali ng agent. Ituring ang skills na parang code, na may may-ari at change log.
  • Suriin ang seguridad bago mag-install ng third-party na skills. Maaaring may kasamang script ang isang skill. Binabanggit ng bagong governance roadmap ang security guidance dahil dito; hangga't wala pa ito, basahin ang iyong ini-install.
  • Sukatin ang pagiging natatangi, hindi lamang ang bilis. Kung nagsisimulang magmukhang katulad ng sa mga kakumpitensya mo ang content na isinulat ng iyong agent, masyadong manipis ang iyong konteksto.

Hindi kapana-panabik ang mga open standard hangga't hindi mo kailangang magpalit ng tool. Pagdating ng araw na iyon, ang mga team na nagsulat ng kanilang know-how sa isang portable na format ay makakalipat sa loob ng isang linggo. Ang iba ay magsisimula ulit.

FAQ

Ano ang Agent Skill?

Ayon sa Anthropic, ang skill ay isang folder na naglalaman ng SKILL.md file na nagtuturo sa isang AI agent ng partikular na gawain o domain, kasama ang anumang script o reference material na kailangan ng gawain.

Sino na ngayon ang nagpapanatili ng Agent Skills standard?

Ibinigay ng Anthropic ang standard, ang pangalan, logo, GitHub organisation at ang domain na agentskills.io nito sa Agentic AI Foundation sa ilalim ng Linux Foundation. Pinapanatili ito ng mga engineer mula sa Anthropic, Google, OpenAI at iba pang kumpanya bilang mga indibidwal.

Paano magagamit ng mga marketer ang Agent Skills?

Sa pagsulat ng mga prosesong paulit-ulit, gaya ng brief, competitor review o campaign report, kasama ang mga patakaran ng brand at mga halimbawa, upang sundin ng mga AI agent sa iba't ibang tool ang sariling pamamaraan ng team sa halip na mga generic na default.
