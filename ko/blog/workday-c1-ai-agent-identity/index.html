Workday의 C1.ai 인수: 마케팅 에이전트에도 ID가 필요하다

Workday가 사람과 AI 에이전트의 접근 권한을 관리하는 C1.ai를 인수하기로 했습니다. CRM과 광고 계정을 다루는 마케팅 에이전트에도 같은 규칙이 필요합니다.

뉴스: Workday, 사람과 에이전트를 위한 에이전트형 ID 플랫폼 C1.ai 인수 최종 계약 체결(2026년 10월 13일)

글: Aleks Farseev 교수2026년 11월 8일4분 읽기

신입 직원이 입사하면 누군가가 계정을 만들고, 무엇을 볼 수 있는지 정하고, 퇴사하면 접근 권한을 회수합니다. 새로운 AI 에이전트가 마케팅 팀에 합류하면 누가 그 일을 합니까? 10월 13일 Workday는 바로 그 질문에 답하는 것이 사업의 전부인 회사를 인수하겠다고 발표했습니다.

무슨 일이 있었나

Workday의 보도자료에 따르면 Workday는 “사람과 에이전트를 위한 에이전트형 ID 플랫폼” C1.ai를 인수하는 최종 계약을 체결했습니다. 인수 가격은 공개되지 않았으며, 거래는 통상적인 조건을 충족하는 전제로 2027년 1월 31일에 끝나는 Workday 2027회계연도 4분기에 완료될 예정입니다.

C1.ai는 이메일, CRM, 코드 저장소, 재무 시스템, 클라우드 인프라 같은 비즈니스 시스템에 연결됩니다. 사람과 에이전트 각각에게 필요할 때 접근 권한을 부여하고 필요 없어지면 회수합니다. 자체 설명에 따르면 이 플랫폼은 범위가 제한된 접근, 강제되는 정책, 사람의 승인, 모든 행동의 기록을 제공합니다.

보도자료는 두 가지 수치로 문제를 제시합니다. C1.ai의 조사를 인용해 미국 대기업의 95%가 이미 자율 에이전트를 운영하고 있다고 하고, Deloitte를 인용해 이를 관리하는 성숙한 방법을 갖췄다고 답한 곳은 21%에 불과하다고 말합니다. Workday의 Gerrit Kazmaier는 “오늘날 기업은 사람과 AI 에이전트가 결합된 인력으로 운영됩니다”라고 말했습니다. C1.ai의 CEO Alex Bovee는 더 직설적으로 표현했습니다. “기업은 어제의 IT 티켓으로 AI 시대를 지킬 수 없습니다.”

왜 중요한가

마케팅은 그렇게 느껴지지 않더라도 회사에서 권한이 가장 많이 얽힌 부서 중 하나입니다. 유능한 마케팅 에이전트가 건드려야 할 것들을 떠올려 보십시오. 고객 데이터가 담긴 CRM, 예산이 걸린 광고 계정, 분석 도구, 콘텐츠 관리 시스템, 브랜드를 대변하는 소셜 계정, 이메일 플랫폼, 공개 전 계획이 가득한 공유 드라이브.

대부분의 팀은 이 접근 권한을 예전 방식으로 부여합니다. 누군가 로그인 정보를 공유합니다. API 키가 스프레드시트에 들어 있습니다. 더 쉬워서 도구에 “관리자” 권한을 줍니다. 사람에게도 이미 위험한 방식이었습니다. 쉬지 않고 기계의 속도로 행동하는 에이전트에게는 그것이 가장 큰 리스크가 됩니다.

C1.ai의 제안이 제대로 짚은 것은 답의 형태입니다. 작업 범위로 제한되고, 필요한 시점에 부여되며, 필요하면 사람이 승인하고, 기록되는 접근 권한입니다. 이것은 IT의 세부 사항이 아닙니다. 에이전트에게 실제 업무를 안전하게 맡길 수 있는지를 결정합니다.

제 연구가 말하는 것

에이전트가 등장하기 훨씬 전, 제 팀은 더 단순한 ID 문제를 연구했습니다. Person, Organization, or Personage: Towards User Account Type Prediction in Microblogs(EGOSE 2018)에서 저희는 개인, 조직, 유명인 계정을 구분하는 방법을 연구했습니다. 동기는 어떤 종류의 행위자가 만든 행동인지 모르면 그 행동을 올바르게 해석할 수 없다는 것이었습니다.

이제 같은 원칙이 회사 내부에 적용됩니다. 마케팅 스택의 모든 행동은 출처를 밝힐 수 있어야 합니다. 이 예산 변경은 사람이 했는가, 사람을 대신한 에이전트가 했는가, 자동화 규칙이 했는가? 그렇지 않으면 결과를 감사하거나, 실수를 설명하거나, 효과가 있었던 것에서 배울 수 없습니다. Against Opacity부터 MindFuse까지 저희의 설명 가능한 AI 연구에서 설명은 어떤 입력과 어떤 결정이 결과로 이어졌는지 아는 데 달려 있습니다. ID는 첫 번째 입력입니다.

저는 이것을 제가 Forbes 칼럼에서 주장해 온 변화, 즉 마케터가 수작업 콘텐츠 제작자에서 AI 도구의 큐레이터로 바뀌는 흐름의 일부로도 봅니다. 에이전트를 큐레이션하는 일에는 각 에이전트가 무엇을 할 수 있는지 정하는 것도 포함됩니다.

마케팅 운영이 지금 해야 할 일

  • 모든 에이전트에게 고유한 ID를 주십시오. 사람의 로그인 정보를 공유하지 마십시오. 플랫폼이 서비스 계정이나 범위가 제한된 API 키를 지원하지 않는다면 위험 신호로 보십시오.
  • 작업별로 범위를 정하십시오. 보고서를 쓰는 에이전트에게 필요한 것은 분석 도구의 읽기 권한이지 광고 예산의 쓰기 권한이 아닙니다.
  • 되돌릴 수 없는 행동에는 승인을 요구하십시오. 게시, 기준액 이상의 지출, 데이터 삭제에는 사람의 “예”가 필요해야 합니다.
  • 접근 권한에 만료를 두십시오. 캠페인이나 작업 기간 동안만 권한을 부여하고, 이후에는 자동으로 회수하십시오.
  • 기록하고 검토하십시오. 에이전트의 행동 기록을 남기고, 특히 지출이나 메시지에 예상치 못한 일이 생긴 뒤에는 반드시 살펴보십시오.
  • 오프보딩에 에이전트를 포함하십시오. 벤더, 도구, 에이전시와의 관계가 끝나면 함께 들어온 에이전트와 키를 회수하십시오.

Workday의 인수는 기업용 소프트웨어 세계가 이제 에이전트를 인력의 일원으로 다룬다는 신호입니다. 마케팅도 그래야 하며, 그 출발점은 누가 열쇠를 갖느냐입니다.

FAQ

C1.ai란 무엇인가요?

Workday에 따르면 C1.ai는 이메일, CRM, 코드 저장소, 재무 시스템, 클라우드 인프라 같은 비즈니스 시스템에 연결되는 에이전트형 ID 플랫폼으로, 사람과 AI 에이전트에게 필요할 때 접근 권한을 부여하고 필요 없어지면 회수하며, 범위가 제한된 접근, 정책, 사람의 승인, 행동 기록을 제공합니다.

Workday의 C1.ai 인수는 언제 완료되나요?

Workday는 통상적인 거래 완료 조건을 충족하는 전제로, 2027년 1월 31일에 끝나는 2027회계연도 4분기에 거래가 완료될 것으로 예상합니다. 인수 가격은 공개되지 않았습니다.

마케팅의 AI 에이전트에 왜 고유한 ID가 필요한가요?

에이전트가 점점 더 고객 데이터, 광고 예산, 브랜드 채널을 다루기 때문입니다. 분리되고, 범위가 제한되며, 기록되는 ID가 있어야 각 에이전트가 할 수 있는 일을 제한하고, 위험한 행동에 승인을 요구하며, 감사를 위해 모든 변경의 출처를 밝힐 수 있습니다.
