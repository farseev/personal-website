韓国、全国民に無料AIエージェント：新たな玄関口

韓国は、SKT、KT、Kakao が運営し、KakaoTalk、通話、テキストを通じて全国民に無料のAIエージェントを提供する計画です。公共のエージェント層がブランドに意味することを解説します。

ニュース：韓国の「AI for All」運営事業者が、メッセンジャー、通話、テキストを通じて全国民に無料のエージェント型AIサービスを提供する計画を説明（2026年9月4日）

著者：Prof. Aleks Farseev2026年11月8日4分で読めます

多くの国がAIエージェントをどう規制するかを議論しています。韓国は全員に一つずつ提供しようとしています。9月、政府と3つの運営事業者グループが「AI for All」の仕組みを示しました。国民のために予約や支払いを行える無料のエージェントで、メッセンジャー、電話、テキストメッセージで利用できます。ブランドにとって、これは顧客への新たな玄関口になる可能性があります。

何が起きたのか

The Korea Times によると、科学技術情報通信部とプロジェクトの運営事業者は9月4日に説明会を開きました。韓国は2026年末までに全国民向けの無料のエージェント型AIサービスを開始する計画で、ベータテストは10月に始まります。エージェントは、モバイルメッセンジャー、電話、テキストメッセージを通じて、予約や支払いといった実際のタスクを完了することを想定しています。

SK Telecom、KT、Kakao が率いる3つのコンソーシアムがサービスを運営します。LG と組む Kakao は KakaoTalk を入り口とし、自社の Kanana と LG の EXAONE モデルを基盤とします。12月までに月間アクティブユーザー500万人、2027年末までに1,000万人を目標としています。KT は、リアルタイム検索に加え、行政、教育、金融、ショッピングのサービスを備えた汎用エージェント Ieum を発表しました。国産のモデルとインフラで運用されます。SK Telecom は、アプリの操作が苦手な人々向けに、認証、公共サービスの申請、支払いを扱う電話とテキストベースのエージェントを提供します。

副首相兼科学技術情報通信部長官の Bae Kyung-hoon は、「私たちの最終的な目標は、新しい国産AIサービスが人々の日常生活に自然に溶け込むことだ」と述べました。記事は予算額を示しておらず、プライバシー対策についても触れていません。

なぜ重要なのか

政府が国民全体の前に取引を行えるエージェントを置き、国産モデルと国内で圧倒的なメッセージアプリを使う計画を見るのは、私にとって初めてです。目標を達成すれば、韓国の消費者の大部分が、検索し、予約し、支払いをしてくれるデフォルトのアシスタントを持つことになります。

それは購買に至る道筋を変えます。今日、レストラン、クリニック、商品を探す韓国の消費者は、検索、地図、アプリ、そしてブランドが可視性を買うプラットフォームを経由します。公共のエージェントが間に入ると、最初の問いはこうなります。エージェントはあなたについて何を知っていて、あなたを選ぶのか。無料で国が支援するエージェントが、通常の意味での広告媒体になる可能性も低いため、有料の可視性という選択肢そのものがないかもしれません。

包摂という観点も重要です。SK Telecom の電話とテキストのエージェントは、明確にアプリの操作が苦手な人々のためのものです。これにより、オンラインでは届きにくかった顧客、特に高齢者にデジタルコマースの扉が開かれます。

私の研究が示すこと

私の研究は一貫して、人々が使う多くのチャネルを通じて人々を理解することをテーマとしてきました。Harvesting Multiple Sources for User Profile Learning（ICMR 2015）と、私たちの360°ユーザープロファイリングの概説では、各チャネルが同じ人物の異なる側面を映し出すという考え方を示しました。韓国の計画は、エージェントへの音声通話のような新しいチャネルを加え、それを少数のエージェント運営事業者に集中させます。それらのエージェントを運営する者は、日々の意図について驚くほど完全な像を手にすることになります。そのため、説明会では触れられなかったプライバシー設計が中心的な問いになります。

ブランドの側について、私は Forbes でマーケティングにおけるAIエージェントのさまざまな活用法を論じてきました。その裏返しが、エージェントに向けたマーケティングです。国民のためにレストランや商品を選ぶエージェントは、在庫状況、価格、所在地、ポリシーといった、構造化された信頼できる情報に依拠するでしょう。それを韓国のプラットフォームが使う形式で明確に公開するブランドは、エージェントに選ばれやすくなります。

韓国のブランド、そして韓国に注目するブランドが今すべきこと

  • 事業情報をエージェントが読み取れるようにしましょう。これらのエージェントが参照しそうなプラットフォーム上で、営業時間、価格、在庫状況、予約方法を正確に保ってください。
  • 人間がフォームに入力しなくても、エージェントが完了できる予約と支払いのフローに対応しましょう。
  • 音声とテキストを前提に設計しましょう。電話ベースのエージェントを通じて連絡してくる顧客がいるなら、情報は視覚要素なしでも意味が通じなければなりません。
  • ベータ版に注目しましょう。10月のテストで、エージェントがどの情報源やパートナーに依拠するのかが見えてくるでしょう。
  • 自社の連携ではプライバシーを真剣に扱いましょう。公共のエージェントと接続する場合は、タスクに必要なものだけを収集してください。
  • 地域全体で考えましょう。他のアジア諸国の政府も注視しています。公共のエージェント層は他の国にも現れるかもしれません。

韓国は、AIエージェントが公共インフラになったときに何が起きるのかについて、大規模な実験を行っています。ブランドはこれを、検索窓ではなくエージェントが玄関口となる未来を先取りして見る機会として扱うべきです。

よくある質問

韓国の「AI for All」プロジェクトとは何ですか？

全国民に無料のエージェント型AIサービスを提供する政府のプログラムです。The Korea Times によると、エージェントはメッセンジャー、電話、テキストメッセージを通じて予約や支払いなどのタスクを処理し、10月からベータテストを行い、2026年末までの開始を予定しています。

韓国の無料AIエージェントを運営するのはどの企業ですか？

SK Telecom、KT、Kakao が率いる3つのコンソーシアムです。Kakao は LG と協力して KakaoTalk を活用し、KT は Ieum というエージェントを提供し、SK Telecom は電話とテキストベースのエージェントに注力します。

ブランドは公共のAIエージェントにどう備えられますか？

事業情報を正確かつ機械可読に保ち、エージェントが完了できる予約と支払いのフローに対応し、音声やテキストでも使える情報にし、あらゆる連携を通じて収集する個人データを最小限に抑えることです。
