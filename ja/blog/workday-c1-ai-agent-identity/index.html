Workday が C1.ai を買収：マーケティングエージェントにもIDが必要

Workday は、人とAIエージェントのアクセスを管理する C1.ai の買収に合意しました。CRM や広告アカウントに触れるマーケティングエージェントにも同じルールが必要です。

ニュース：Workday が、人とエージェントのためのエージェント型IDプラットフォーム C1.ai の買収で最終合意（2026年10月13日）

著者：Prof. Aleks Farseev2026年11月8日4分で読めます

新しい社員が入社すると、誰かがアカウントを作成し、何を閲覧できるかを決め、退職時にはアクセス権を削除します。新しいAIエージェントがあなたのマーケティングチームに加わったとき、それは誰が行うのでしょうか。10月13日、Workday は、まさにその問いに答えることを事業とする企業を買収すると発表しました。

何が起きたのか

Workday のプレスリリースによると、同社は「人とエージェントのためのエージェント型IDプラットフォーム」である C1.ai の買収について最終合意を締結しました。買収価格は公表されておらず、慣例的な条件を満たすことを前提に、2027年1月31日に終了する Workday の2027会計年度の第4四半期に完了する見込みです。

C1.ai は、メール、CRM、コードリポジトリ、財務システム、クラウドインフラなどの業務システムと連携します。人やエージェントに、必要なときにアクセス権を付与し、不要になれば削除します。同社自身の説明によると、このプラットフォームは、範囲を限定したアクセス、適用されるポリシー、人間による承認、そしてすべての操作の記録を提供します。

リリースは、2つの数字で問題を示しています。C1.ai の調査を引用して、米国の大企業の95%がすでに自律型エージェントを運用しているとし、Deloitte を引用して、それを管理する成熟した方法があると回答したのはわずか21%だとしています。Workday の Gerrit Kazmaier は「今日の企業は、人とAIエージェントが組み合わさった労働力で動いている」と述べました。C1.ai の CEO、Alex Bovee はより率直に「企業は昨日のITチケットでAI時代を守ることはできない」と語りました。

なぜ重要なのか

マーケティングは、そうは感じられないかもしれませんが、社内で最も権限が集中する部門の一つです。高性能なマーケティングエージェントが触れる必要があるかもしれないものを考えてみてください。顧客データを含む CRM、予算のある広告アカウント、アナリティクス、コンテンツ管理システム、ブランドを代弁するソーシャルアカウント、メール配信プラットフォーム、未発表の計画が詰まった共有ドライブです。

多くのチームは、こうしたアクセス権を昔ながらのやり方で付与しています。誰かがログイン情報を共有する。APIキーがスプレッドシートに置かれている。そのほうが楽だったからという理由で、ツールに「管理者」権限が与えられる。人の場合でもすでにリスクがありました。継続的に稼働し、機械の速度で行動するエージェントの場合、それが最大のリスクになります。

C1.ai の提案が的を射ているのは、答えの形です。タスクに合わせて範囲を限定し、必要なときに付与し、必要に応じて人間が承認し、記録されるアクセスです。これはITの細部の話ではありません。エージェントに実際の仕事を安全に任せられるかどうかを決めるものです。

私の研究が示すこと

エージェントが登場するずっと前、私のチームはより単純なIDの問題に取り組みました。Person, Organization, or Personage: Towards User Account Type Prediction in Microblogs（EGOSE 2018）では、個人、組織、著名人のアカウントを見分ける方法を研究しました。その動機は、どのような種類の主体が行動したのかがわからなければ、行動を正しく解釈できないということでした。

同じ原則が今、企業の内部にも当てはまります。マーケティングスタックのすべての操作は、誰によるものか特定できるべきです。この予算変更は人が行ったのか、人に代わってエージェントが行ったのか、自動化されたルールが行ったのか。それがわからなければ、結果を監査することも、ミスを説明することも、うまくいったことから学ぶこともできません。Against Opacity から MindFuse に至る私たちの説明可能なAIの研究では、説明は、どの入力とどの意思決定が結果につながったかを知ることにかかっています。IDは最初の入力なのです。

これはまた、私が Forbes のコラムで論じてきた、手作業のコンテンツ制作者からAIツールのキュレーターへというマーケターの転換の一部でもあると考えています。エージェントをキュレーションすることには、それぞれに何を許可するかを決めることも含まれます。

マーケティング・オペレーションが今すべきこと

  • すべてのエージェントに固有のIDを与えましょう。人間のログイン情報の共有は禁止です。プラットフォームがサービスアカウントや範囲を限定したAPIキーに対応していない場合は、危険信号とみなしてください。
  • タスクごとに範囲を限定しましょう。レポートを書くエージェントに必要なのはアナリティクスの読み取り権限であり、広告予算の書き込み権限ではありません。
  • 元に戻せない操作には承認を必須にしましょう。公開、一定額を超える支出、データの削除には、人間の承認が必要であるべきです。
  • アクセス権に期限を設けましょう。キャンペーンやタスクの期間中だけアクセス権を付与し、終了後は自動的に削除してください。
  • 記録し、見直しましょう。エージェントの操作の記録を残し、特に支出やメッセージに予期しないことが起きた後には、それを確認してください。
  • オフボーディングにエージェントを含めましょう。ベンダー、ツール、代理店との関係が終了したら、それに伴って導入されたエージェントとキーを無効化してください。

Workday の買収は、企業向けソフトウェアの世界が今やエージェントを労働力の一員として扱っていることを示しています。マーケティングもそうすべきです。まずは、誰に鍵を渡すかから始めましょう。

よくある質問

C1.ai とは何ですか？

Workday によると、C1.ai はメール、CRM、コードリポジトリ、財務システム、クラウドインフラなどの業務システムと連携するエージェント型IDプラットフォームで、人とAIエージェントに必要なときにアクセス権を付与し、不要になれば削除します。範囲を限定したアクセス、ポリシー、人間による承認、操作の記録を備えています。

Workday による C1.ai の買収はいつ完了しますか？

Workday は、慣例的な完了条件を満たすことを前提に、2027年1月31日に終了する2027会計年度の第4四半期に買収が完了すると見込んでいます。買収価格は公表されていません。

マーケティングのAIエージェントに固有のIDが必要なのはなぜですか？

エージェントが顧客データ、広告予算、ブランドのチャネルに触れることが増えているからです。分離され、範囲を限定され、記録されるIDがあれば、各エージェントができることを制限し、リスクの高い操作に承認を求め、監査のためにすべての変更の主体を特定できます。
