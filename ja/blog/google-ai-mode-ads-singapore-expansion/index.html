Google AI Mode の広告がシンガポールなどに上陸

Google は AI Mode の広告をシンガポール、マレーシア、フィリピンを含む10市場に拡大しています。広告が回答の中に置かれると何が変わるのかを解説します。

ニュース：Google が AI Mode の広告を新たに10市場に拡大し、米国でマルチターン広告を開始（2026年10月28日）

著者：Prof. Aleks Farseev2026年11月8日4分で読めます

10月28日、Google は対話型検索体験である AI Mode の広告を、さらに10市場に拡大すると発表しました。シンガポールもその一つです。マレーシアとフィリピンも含まれます。東南アジアのマーケターにとって、AIの回答の中にどう現れるかという問いは、もはや理論上の話ではなくなりました。

何が起きたのか

The Keyword への投稿で、Google の検索広告を統括する Shashi Thakur は、Google がオーストラリア、カナダ、インド、ケニア、マレーシア、ニュージーランド、ナイジェリア、パキスタン、フィリピン、シンガポールで AI Mode の広告を拡大していると述べました。ブラジル、メキシコ、英国は2026年第4四半期に予定されています。米国では、ユーザーが AI Mode 内で行うフォローアップの質問に表示されうるマルチターン広告も開始します。広告には「スポンサー」のラベルが付きます。

Google はこの動きを、2つの社内データで裏づけました。AI Mode のクエリは従来の検索より平均で3倍長いとしています（同社の AI Mode レポート、米国、2026年5月）。また、AI Mode 内のスポンサー付き商品リストとオーガニック商品リストのクリック率は、すでに同程度であるとしています（社内データ、米国、2026年8月20日〜9月3日）。

同じ日、Alphabet は第3四半期の決算を発表しました。Relevant Audience による決算の読み解きによると、Google 検索およびその他の収益は前年比12%増の633.5億米ドルで、前四半期からはほぼ横ばいでした。Sundar Pichai はクエリの伸びを過去5年で最高と表現しました。レポートは、経営陣のコメントに基づき、収益の伸びの鈍化の一因を AI Mode のクエリの収益化の低さにあるとしています。

なぜ重要なのか

これらの事実を合わせると、シンプルな構図が見えてきます。人々はより長く、より具体的な質問をしています。Google はそれに対話で答えています。そして Google は今、AI Mode の収益力を高める商業的な理由があるこのタイミングで、私たちの地域において、その対話の中の枠を販売しているのです。

広告主にとって、3倍長いクエリは贈り物です。「ランニングシューズ」からはほとんど何もわかりません。「湿度の高い気候向けの軽量ランニングシューズ、幅広の足、200シンガポールドル以下、初めてのハーフマラソン用」からは、気候、体、予算、目標がわかります。それはキーワードではなく、プロファイルです。

マルチターン広告はさらに重要です。対話では、意図は一往復ごとに積み上がっていきます。3つ目のフォローアップ質問に表示される広告は、一続きの語句ではなく、その人がそれまでに話したことすべてにマッチングされます。

私の研究が示すこと

私はキャリアの大半を一つの考えに費やしてきました。人は、一つの信号を見るよりも多くの信号を組み合わせたほうがよく理解できるということです。Harvesting Multiple Sources for User Profile Learning（ICMR 2015）では、マルチソースのソーシャルメディアデータセットと、ユーザーの人口統計的属性と移動に関するプロファイルを学習するアンサンブルモデルを構築しました。その後、I Know Where You Are Coming From（AAAI 2020）では、データソースの選択によってAIのユーザーモデルの精度が変わることを示しました。

マルチターンの対話は、数分間に圧縮されたマルチソースの信号です。一往復ごとに、同じ人物についての新たな視点が加わります。何を必要としているのか、何を除外するのか、何を大切にしているのか。プロファイリング研究の教訓はそのまま当てはまります。価値は組み合わせにあり、順序が重要です。対話全体を読む広告システムは、単一のクエリに反応するシステムに勝ち、対話全体に向けて書く広告主は、キーワードに向けて書く広告主に勝つでしょう。

2つ目の教訓はラベルに関するものです。Google によると、AI Mode 内では、スポンサー付きとオーガニックの商品リストのクリック率はすでに同程度です。これは短期的には広告主にとって良いニュースです。そしてそれこそが、「スポンサー」のラベルが明確であり続けなければならない理由でもあります。私は長年、贖いのマーケティング（redemptive marketing）に関する Forbes のコラムなどで、透明性とパフォーマンスは対立するものではないと論じてきました。アンサーエンジンでは、信頼こそが製品です。人々が回答と広告を見分けられなくなれば、どちらも価値を失います。

東南アジアのマーケターが今すべきこと

  • ブリーフをキーワードではなく状況を軸に書き直しましょう。顧客が実際に尋ねる長く具体的な質問を、顧客自身の言葉で書き出し、ランディングページがそれに平易に答えているか確認してください。
  • 対話を単位として扱いましょう。最初の質問の後に続きそうな2つ目、3つ目の質問を整理してください。マルチターン広告が表示されるのはそこだからです。
  • 機械にきれいな商品データを与えましょう。アンサーエンジンは解析できるものを引用します。価格、サイズ、在庫状況、ポリシーはページ上に明示してください。
  • クリックではなく、増分効果を測りましょう。クリック率が同程度でも、AI Mode の広告が、それがなくても発生した売上ではない売上を生んだかどうかはわかりません。予算を移す前にホールドアウトテストを実施してください。
  • オーガニックの足元も固めておきましょう。スポンサー付きとオーガニックのリストが並んで表示されるなら、オーガニックの回答で引用される情報源になることは、依然として最も安価に得られる可視性です。

10市場は始まりであって、最終形ではありません。アンサーエンジンがシンガポール、クアラルンプール、マニラで同時に枠の販売を始めるなら、地域チームはそれを10の別々の実験としてではなく、現地ごとのニュアンスを持つ一つのチャネルとして計画すべきです。

よくある質問

Google の AI Mode で広告が表示される市場はどこですか？

Google によると、オーストラリア、カナダ、インド、ケニア、マレーシア、ニュージーランド、ナイジェリア、パキスタン、フィリピン、シンガポールで AI Mode の広告を拡大しており、ブラジル、メキシコ、英国は2026年第4四半期に予定されています。マルチターン広告は米国で開始されます。

AI Mode のマルチターン広告とは何ですか？

最初のクエリだけでなく、AI Mode の対話の中のフォローアップの質問にも表示されうる広告です。Google によると、まず米国で開始され、「スポンサー」のラベルが付きます。

広告主は、AI検索の広告にどう備えるべきですか？

長く状況に即した質問に向けて書き、顧客が尋ねそうなフォローアップの質問を整理し、明確で解析しやすい商品情報を公開し、クリック率だけでなくホールドアウトテストで成果を判断することです。
