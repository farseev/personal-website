ChatGPT 広告が対話に：Sponsored Agents

OpenAI は ChatGPT 内で Sponsored Agents をテストし、ChatGPT 広告を89か国に拡大しました。広告が言葉を返すとき、表示と誠実さそのものが製品になります。

ニュース：OpenAI が ChatGPT で Sponsored Agents をテストし、ChatGPT 広告をさらに26か国に拡大（2026年10月21日）

著者：Prof. Aleks Farseev2026年11月8日4分で読めます

検索広告は一文とリンクです。ChatGPT の Sponsored Agent は対話です。9月から10月にかけて、OpenAI は言葉を返す広告のテストを開始し、ChatGPT 広告を89か国に広げました。この2つの動きが合わさって、広告とは何かが変わります。

何が起きたのか

The Next Web によると、9月16日、OpenAI は一部の米国の広告主とともに Sponsored Agents のテストを開始しました。ユーザーは広告をクリックした後、OpenAI が「明確に表示された会話」と呼ぶものを「ChatGPT 内の企業がスポンサーするエージェント」と始めることを選べます。たとえば、ダイニングテーブルが部屋に合うかどうかや、その仕上げの手入れ方法を尋ね、その後リンクから企業のサイトに移動できます。OpenAI は、スポンサー付きの会話は「ChatGPT の独立した回答とは区別される」としています。

同じ発表では、広告主向けのツールも登場しました。ChatGPT 内で平易な言葉を使ってキャンペーンを作成・分析できる Ads Manager プラグイン、ランディングページに基づく広告コピーと画像の提案、そして見出しを会話の文脈に合わせて調整し、広告コピーをユーザーの言語に翻訳するオプトイン機能です。HubSpot と Shopify が最初の CRM およびEコマースのパートナーとして挙げられました。

10月21日、Reuters の報道によると、OpenAI は ChatGPT 広告をさらに26か国に拡大し、合計89か国とします。対象には、カンボジア、バングラデシュ、パキスタンなど、中南米、欧州、アフリカ、アジアの市場が含まれます。同社によると、10万を超える広告主がキャンペーンを実施し、広告事業は8月に年換算売上高10億米ドルのペースに達しました。広告は Free プランと Go プランにのみ表示され、Plus、Pro、Enterprise は引き続き広告なしです。

なぜ重要なのか

広告がエージェントになると、3つのことが変わります。

第一に、広告が質問に答えられるようになります。答えが正確であれば、静的なバナーよりもユーザーにとって良いものです。同時に、新たな責任も生じます。製品の機能を誇張するスポンサー付きエージェントは、しゃべる誤解を招く広告です。

第二に、アシスタントと広告主の境界は、やり取りのたびに見えていなければなりません。ChatGPT の独立した回答とは区別される、明確に表示された会話という OpenAI の表現は、正しい原則です。その価値は、チャットの途中にいる普通のユーザーにとって、その区別がどれだけ明確に感じられるかに完全にかかっています。

第三に、注目の市場が二層化します。有料ユーザーには広告が表示されず、無料ユーザーには表示されます。ほとんどの人が無料プランを使う急成長市場では、ChatGPT は大規模な広告チャネルになりつつあります。有料加入者が多い市場では、価値の高いオーディエンスにはオーガニックな回答を通じてしか届かなくなるでしょう。

私の研究が示すこと

スポンサー付きエージェントは、リアルタイムのパーソナライゼーションです。会話そのものがプロファイルになります。パーソナリティに基づくコンテンツ推薦（ACM Multimedia 2022）とパーソナリティに基づくコンテンツ生成（WSDM 2021）に関する私の研究では、人が何に反応するかを推定し、それに合わせてコンテンツを調整する方法を探りました。これらの手法は機能します。だからこそガードレールが重要なのです。ユーザー一人ひとりのパーソナリティに合わせて説得の仕方を変えるエージェントは非常に効果的であり、透明性がなければ非常に悪用しやすいものです。

私は Forbes で、透明性とパフォーマンスは互いを強め合うことができるという贖いのマーケティング（redemptive marketing）の考え方を提唱してきました。対話型広告は、その考え方が試される場です。長期的に勝つのは、スポンサー付きエージェントが限界について正直で、合わない場合には「この製品はあなたには向いていません」と言い、手に負えない質問は人間に引き継ぐブランドでしょう。

自動翻訳機能にも注意が必要です。広告コピーをユーザーの言語に翻訳するのは便利ですが、市場ごとに規制が異なる訴求についてはリスクがあります。

広告主が今すべきこと

  • スポンサー付きエージェントのスクリプトより先にルールを書きましょう。どの訴求が許されるのか、どの質問を断らなければならないのか、いつ人間に引き継ぐのかを決めてください。
  • 自社の事実に基づかせましょう。製品仕様、価格、ポリシー、お手入れ方法は、モデルの一般知識ではなく、管理された情報源から提供されるべきです。
  • 翻訳されたコピーは、規制対象の訴求がないか確認しましょう。特に健康、金融、子ども向け製品では注意が必要です。
  • 両方の層に備えましょう。無料ユーザーがオーディエンスである場合は有料の掲載を使い、広告なしプランのユーザーに向けてはオーガニックな可視性に投資してください。
  • クリックの先まで測定しましょう。会話の長さだけでなく、会話が購入、返品、苦情につながっているかを追跡してください。

検索広告は、クエリに向けて書くことを教えてくれました。対話型広告は、信頼できる販売員のように、大規模に、あらゆる言語で答えることを教えてくれるでしょう。それはより難しく、より興味深いことです。

よくある質問

ChatGPT の Sponsored Agents とは何ですか？

ユーザーが ChatGPT で広告をクリックした後に話すことを選べる、企業がスポンサーするエージェントです。OpenAI はこの体験を、ChatGPT の独立した回答とは区別される、明確に表示された会話と説明しています。テストは一部の米国の広告主とともに始まりました。

ChatGPT 広告は何か国で利用できますか？

Reuters は2026年10月21日、OpenAI が ChatGPT 広告をさらに26か国に拡大し、合計89か国にすると報じました。

有料の ChatGPT ユーザーにも広告は表示されますか？

Reuters によると、広告は ChatGPT の Free プランと Go プランにのみ表示され、Plus、Pro、Enterprise のサブスクリプションは引き続き広告なしです。
