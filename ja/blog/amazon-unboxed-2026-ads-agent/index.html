Amazon Ads Agent：unBoxed 2026 でリテールメディアがエージェント化

unBoxed 2026 で Amazon は購入ツールを Amazon Ads Agent に統合し、対話型の効果測定とAIクリエイティブを導入しました。人の手に残すべきものを考えます。

ニュース：Amazon Ads が unBoxed 2026 で Amazon Ads Agent、Full-Funnel Campaigns、AIクリエイティブツール、Ads MCP server を発表（2026年9月30日）

著者：Prof. Aleks Farseev2026年11月8日4分で読めます

リテールメディアには、他のデジタル広告に対する一つの強みが常にありました。購入のすぐ隣にあることです。unBoxed 2026 で、Amazon は2つ目の強みを加えました。購入からクリエイティブ、効果測定まで、広告主が同社プラットフォーム上で行うほぼすべての作業の前面にAIエージェントを置いたのです。

何が起きたのか

Amazon 自身のまとめ The 11 biggest takeaways from unBoxed 2026 に、発表内容が列挙されています。目玉は Amazon Ads Agent です。これは従来の DSP と Ads Console を統合した一元的な購入体験で、Sponsored ads、Full-Funnel Campaigns、DVA+ をカバーし、対話型AI体験はクローズドベータを拡大して提供されています。

Full-Funnel Campaigns では、動画、ディスプレイ、オーディオにわたるチャネルミックス、クリエイティブ、オーディエンス、最適化をAIが管理します。Amazon によると、ベータテスターは長期的な広告費用対効果が67%向上し、ブランド新規顧客の獲得コストが29%低下しました。Ads Agent に組み込まれたAIクリエイティブツールは、既存の商品素材からディスプレイ広告や動画を生成します。Amazon によると、これを使った広告主は、以前の実績と比べて商品カバレッジが最大71%増加し、売上が最大15%伸びました。

効果測定では、Ads Agent は対話型のクエリを通じて約1,000の指標にアクセスでき、可視化と同業他社のベンチマークを含むビジネスレビューを作成します。AMC Expert Tool は、自然言語の依頼を Amazon Marketing Cloud の SQL に変換します。Amazon はまた、外部のエージェントが Amazon Ads と連携できる Ads MCP Server（Lite）、Alexa for Shopping 内でブランドの差別化要素を提示する Branded Conversations、地域サービス向けに Yelp を主要パートナーとする Sponsored Services も発表しました。パフォーマンスの数値はすべて Amazon 自身によるものです。

なぜ重要なのか

2つの変化が際立っています。

1つ目は、広告プラットフォームのインターフェースが対話になりつつあることです。約1,000の指標にわたるビジネスレビューを平易な言葉で依頼できれば、多くの単調な作業がなくなります。それはまた、どんな質問をするかによって得られる答えが変わることも意味します。かつてアナリストは、データのどの切り口が公平かを判断するのに何時間も費やしていました。チャット画面は、その手順を飛ばすことを容易にしてしまいます。

2つ目は、プラットフォームがフルファネルを引き受けつつあることです。AIがチャネルミックス、クリエイティブ、オーディエンスを選び、同じプラットフォームが結果を測定するなら、広告主は、どの意思決定を委ねるのか、成果をどう検証するのかを明確にする必要があります。

私の研究が示すこと

効果測定におけるこの緊張関係について、私は e27 の Every dashboard is green. So why can't anyone say what worked? で書きました。より良いレポーティングツールが、自動的により良い理解を生むわけではありません。自然言語による分析は、ダッシュボードの作成をさらに容易にするでしょう。「何と比べて？」と問う規律は、重要性が下がるどころか、むしろ高まります。

クリエイティブの面では、私たちの研究はパフォーマンスの予測とその説明に焦点を当ててきました。Fusing Predictive and Large Language Models for Actionable Recommendations in Creative Marketing（ACM TOIS 2025）では、パフォーマンス予測とLLMを組み合わせ、クリエイティブのスコアを実行可能な推奨に変えました。商品素材からディスプレイ広告や動画を大規模に生成することは強力ですが、生成はループの半分にすぎません。残りの半分は、どのバリエーションに賭けるべきか、そしてその理由を知ることであり、その知識はプラットフォームの最適化エンジンだけでなく、ブランドのものであるべきです。

ロングテールの観点もあります。Amazon によると、AIクリエイティブツールを使った広告主は、より多くの商品をカバーできました。私の考えでは、AIが真価を発揮するのはロングテールです。人間のチームなら決して個別の広告を書かないような、何千ものSKUやニッチなオーディエンスです。ロングテールとファネル下部の最適化については、Forbes の Low-Funnel Ad Optimization On Social Media Platforms で論じました。品質管理がそれと同じ規模で拡張される限り、機会は本物です。

リテールメディアチームが今すべきこと

  • 委任の範囲を決めましょう。Ads Agent が制御してよいレバー（入札、チャネルミックス、クリエイティブのバリエーション）と、人間の承認が必要なものを書き出してください。
  • 対話型分析には、より良い質問をしましょう。前期比、ホールドアウト比、同業他社のベンチマーク比など、必ず比較を求め、どれを使ったかを記録してください。
  • AIクリエイティブでカバレッジを広げ、その後で絞り込みましょう。ロングテールの商品向けに素材を生成しつつ、パフォーマンスを確認し、弱いバリエーションは定期的に停止してください。
  • 成果の記録は自社でも保持しましょう。重要な結果を自社の分析に書き出し、Amazon と他のチャネルを同じ基準で比較できるようにしてください。
  • MCP は慎重に検討しましょう。自社のエージェントを Amazon Ads に接続するのは効率的ですが、機能する範囲で最も狭い権限を与えてください。

Amazon は広告プラットフォームが言葉を返すようにしました。そこから最も多くを得るのは、難しい質問を投げかけ続けるチームでしょう。

よくある質問

Amazon Ads Agent とは何ですか？

unBoxed 2026 で発表された、Amazon の従来の DSP と Ads Console を統合した一元的な購入体験です。Sponsored ads、Full-Funnel Campaigns、DVA+ をカバーし、対話型AI体験はクローズドベータを拡大して提供されています。

Full-Funnel Campaigns について、Amazon はどのような成果を報告していますか？

Amazon によると、ベータテスターは長期的な広告費用対効果が67%向上し、ブランド新規顧客の獲得コストが29%低下しました。これらは Amazon 自身の数値です。

広告主は Amazon でAI生成の広告クリエイティブをどう活用すべきですか？

人間のチームでは対応できないほど多くの商品やオーディエンスをカバーするために使い、パフォーマンスを定期的に確認し、弱いバリエーションは停止し、どのクリエイティブがなぜ効果的だったのかを自社でも記録しておくことです。
