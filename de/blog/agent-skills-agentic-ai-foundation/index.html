Agent Skills wird herstellerneutral: Warum das Marketer betrifft

Anthropic hat den Standard Agent Skills an die Agentic AI Foundation übergeben. Portables, schriftlich festgehaltenes Know-how ist genau das, was Marketingteams von KI-Agenten brauchen.

Die Nachricht: Anthropic übergibt den offenen Standard Agent Skills an die Agentic AI Foundation unter der Linux Foundation (22. Oktober 2026)

Von Prof. Aleks Farseev8. November 20264 Min. Lesezeit

Manche der wichtigsten KI-Nachrichten wirken auf den ersten Blick langweilig. Am 22. Oktober teilte Anthropic mit, den Standard Agent Skills an die Agentic AI Foundation zu übergeben, ein Gremium unter der Linux Foundation. Kein neues Modell, kein Benchmark. Doch wer Marketing mit KI-Agenten betreibt, für den ist genau diese Infrastruktur entscheidend dafür, ob das eigene Know-how auch das eigene bleibt.

Was passiert ist

Laut Anthropics Beitrag ist ein Skill „ein Ordner mit einer SKILL.md-Datei, die einem Agenten eine bestimmte Aufgabe oder ein Fachgebiet beibringt, zusammen mit allen Skripten oder Referenzmaterialien, die er benötigt“. Anthropic entwickelte das Format beim Bau von Claude Code, weil allgemeinen Agenten oft das prozedurale Wissen fehlte, das echte Geschäftsaufgaben erfordern. Skills wurden im Oktober 2025 eingeführt und Agent Skills im Dezember 2025 als offener Standard veröffentlicht.

Die Verbreitungszahlen sind hoch. Laut Anthropic haben mehr als 70 Agentenplattformen Agent Skills integriert, darunter ChatGPT, Cursor, GitHub Copilot und VS Code, und es wurden 1 Million Skills veröffentlicht und fast 280 Millionen installiert.

Nun gehen der Standard selbst, sein Name und Logo, die GitHub-Organisation und die Domain agentskills.io an die Agentic AI Foundation (AAIF), die Anthropic gemeinsam mit Block und OpenAI gegründet hat und an die es bereits das Model Context Protocol übergeben hatte. Ingenieure von Anthropic, Google, OpenAI und anderen Unternehmen werden ihn als Einzelpersonen pflegen. Die vorgeschlagene Roadmap umfasst versionierte Releases, ein formelles Vorschlagsverfahren und Sicherheitsleitlinien für alle, die Skills schreiben und installieren.

Warum das wichtig ist

Jedes Marketingteam, das ich kenne, hat dasselbe verborgene Kapital: seine Arbeitsweise. Wie es ein Briefing schreibt. Welche Wettbewerber es zuerst prüft. Was „markenkonform“ für diesen Kunden in diesem Markt bedeutet. Heute steckt das meiste davon in den Köpfen der Mitarbeitenden und in Foliensätzen, die niemand liest.

Ein Skill ist eine Möglichkeit, dieses Verfahren so aufzuschreiben, dass ein Agent ihm folgen kann. Und ein herstellerneutraler Standard bedeutet, dass Sie es einmal schreiben und erwarten können, dass es in allen Tools Ihres Teams funktioniert. Das ist der Unterschied zwischen dem Aufbau auf einer Plattform und dem Aufbau auf einem Format. Formate überdauern Plattformen.

Es gibt einen zweiten, leiseren Vorteil. Ein Skill ist lesbar. Sie können den Ordner öffnen und sehen, was dem Agenten aufgetragen wurde. In einem Feld, in dem „die KI hat entschieden“ zur gängigen Ausrede wird, ist ein Verfahren im Klartext ein kleines, aber echtes Stück Rechenschaft.

Was meine Forschung sagt

Ich habe in Forbes über die Stufenleiter vom Prompting und Fine-Tuning bis zu RAG und KI-Agenten im Marketing geschrieben sowie über 18 Anwendungen von KI-Agenten im Marketing. Das Muster, auf das ich immer wieder zurückkomme: Agenten scheitern weniger an fehlender Intelligenz als an fehlendem Kontext — den konkreten Daten und dem konkreten Verfahren für die Aufgabe.

Unser jüngstes Paper macht das konkret. In SOMIN: Agentic AI for Automating Professional Visibility and Countering Content Homogenization (SIGIR 2026) beschreiben wir Retrieval-gestützte Agenten, die Fachleuten helfen, unverwechselbare LinkedIn-Inhalte zu schreiben. Die Kernidee: Ein Agent sollte echte Kontextdaten abrufen, bevor er schreibt, damit seine Ausgabe unverwechselbar bleibt, statt sich demselben generischen Text anzunähern, den die Agenten aller anderen erzeugen.

Skills sind der prozedurale Zwilling des Retrievals. Retrieval liefert dem Agenten die Fakten. Ein Skill liefert ihm die Methode. Beide wirken der Homogenisierung entgegen, weil beide das, was für Sie spezifisch ist, in ein System einbringen, das sonst auf den Durchschnitt des Internets zurückfällt. Wenn jede Marke denselben Agenten mit demselben Standardverhalten nutzt, klingt jede Marke gleich. In Ihren Skills steckt Ihr Unterschied.

Was Marketingteams jetzt tun sollten

  • Schreiben Sie drei Verfahren auf, die Sie jede Woche wiederholen, etwa Wettbewerbs-Checks, Kampagnen-Post-Mortems oder Kreativbriefings, als einfache Schritt-für-Schritt-Anleitungen mit Beispielen für gute Ergebnisse.
  • Halten Sie die markenspezifischen Teile getrennt: Tonalität, verbotene Aussagen, rechtliche Hinweise, Marktunterschiede. Diese Teile machen Ihre Ergebnisse zu Ihren eigenen.
  • Versionieren Sie sie. Ändert sich ein Verfahren, ändert sich das Verhalten des Agenten. Behandeln Sie Skills wie Code, mit einem Verantwortlichen und einem Änderungsprotokoll.
  • Prüfen Sie die Sicherheit, bevor Sie Skills von Drittanbietern installieren. Ein Skill kann Skripte enthalten. Die neue Governance-Roadmap nennt aus diesem Grund Sicherheitsleitlinien; solange es sie nicht gibt, lesen Sie, was Sie installieren.
  • Messen Sie Unverwechselbarkeit, nicht nur Geschwindigkeit. Wenn Ihre von Agenten geschriebenen Inhalte denen Ihrer Wettbewerber zu ähneln beginnen, ist Ihr Kontext zu dünn.

Offene Standards sind nicht aufregend, bis Sie das Tool wechseln müssen. Wenn dieser Tag kommt, ziehen die Teams, die ihr Know-how in einem portablen Format aufgeschrieben haben, in einer Woche um. Die anderen fangen von vorn an.

FAQ

Was ist ein Agent Skill?

Laut Anthropic ist ein Skill ein Ordner mit einer SKILL.md-Datei, die einem KI-Agenten eine bestimmte Aufgabe oder ein Fachgebiet beibringt, zusammen mit allen Skripten oder Referenzmaterialien, die die Aufgabe erfordert.

Wer pflegt den Standard Agent Skills jetzt?

Anthropic hat den Standard, seinen Namen, sein Logo, die GitHub-Organisation und die Domain agentskills.io an die Agentic AI Foundation unter der Linux Foundation übergeben. Ingenieure von Anthropic, Google, OpenAI und anderen Unternehmen pflegen ihn als Einzelpersonen.

Wie können Marketer Agent Skills nutzen?

Indem sie wiederholbare Verfahren wie Briefings, Wettbewerbsanalysen oder Kampagnenberichte zusammen mit Markenregeln und Beispielen aufschreiben, sodass KI-Agenten in verschiedenen Tools der eigenen Methode des Teams folgen statt generischen Standardeinstellungen.
