Agent Skills 走向廠商中立：行銷人為何該關注

Anthropic 將 Agent Skills 標準捐贈給 Agentic AI Foundation。可攜、成文的專業知識，正是行銷團隊需要 AI 代理具備的。

新聞：Anthropic 將 Agent Skills 開放標準捐贈給 Linux Foundation 旗下的 Agentic AI Foundation（2026 年 10 月 22 日）

作者：Aleks Farseev 教授2026 年 11 月 8 日閱讀時間 4 分鐘

有些最重要的 AI 新聞，表面上看起來很無聊。10 月 22 日，Anthropic 表示將把 Agent Skills 標準移交給 Linux Foundation 旗下的 Agentic AI Foundation。沒有新模型，也沒有基準測試。但如果你用 AI 代理經營行銷，正是這類底層管線，決定了你的專業知識是否仍然屬於你。

發生了什麼事

根據 Anthropic 的文章，skill 是「一個包含 SKILL.md 檔案的資料夾，用來教導代理執行特定任務或領域的工作，並附上它所需的任何腳本或參考資料」。Anthropic 在打造 Claude Code 時開發了這個格式，因為通用型代理往往缺乏真實商業任務所需的程序性知識。它於 2025 年 10 月推出 skills，並於 2025 年 12 月將 Agent Skills 發布為開放標準。

採用數字相當可觀。Anthropic 表示，已有超過 70 個代理平台整合了 Agent Skills，包括 ChatGPT、Cursor、GitHub Copilot 與 VS Code，且已有 100 萬個 skills 發布、近 2.8 億次安裝。

如今，標準本身、其名稱與標誌、GitHub 組織以及 agentskills.io 網域，都將移交給 Agentic AI Foundation（AAIF）；Anthropic 與 Block 及 OpenAI 共同創立了該基金會，先前也已將 Model Context Protocol 捐贈給它。來自 Anthropic、Google、OpenAI 及其他公司的工程師將以個人身分維護這項標準。擬議的路線圖包括版本化發布、正式的提案流程，以及針對撰寫與安裝 skills 者的安全指引。

為何重要

我認識的每個行銷團隊，都有同一項隱形資產：他們做事的方式。如何撰寫 brief。先檢查哪些競爭對手。對這個市場的這位客戶而言，「符合品牌」是什麼意思。如今這些大多存在於人們的腦袋裡，以及沒人看的簡報檔中。

skill 是一種把流程寫下來、讓代理得以遵循的方式。而廠商中立的標準，代表你只需寫一次，就能期待它在團隊使用的各種工具中運作。這就是建立在平台上與建立在格式上的差別。格式的壽命比平台長。

還有第二個較不顯眼的好處：skill 是可讀的。你可以打開資料夾，看到代理被要求做什麼。在「是 AI 決定的」逐漸成為常見藉口的領域裡，一份純文字的流程，是雖小但真實的問責。

我的研究怎麼說

我曾在 Forbes 撰文，談行銷中從提示與微調到 RAG 與 AI 代理的進階路徑，以及AI 代理在行銷中的 18 種應用。我一再回到的規律是：代理之所以失敗，與其說是缺乏智慧，不如說是缺乏脈絡——也就是這項工作所需的具體資料與具體流程。

我們最新的論文把這一點具體化。在 SOMIN: Agentic AI for Automating Professional Visibility and Countering Content Homogenization（SIGIR 2026）中，我們描述了協助專業人士撰寫獨特 LinkedIn 內容的檢索增強代理。核心概念是：代理應在撰寫之前先檢索真實的脈絡資料，讓產出保持獨特，而不是趨同於其他人的代理所產出的同一種制式文字。

skills 是檢索在程序面的孿生兄弟。檢索給代理事實，skill 給它方法。兩者都在對抗同質化，因為兩者都把專屬於你的東西注入一個原本會預設為網路平均值的系統。如果每個品牌都以相同的預設行為執行相同的代理，每個品牌聽起來都會一樣。你的 skills，正是你的差異所在。

行銷團隊現在該做什麼

  • 把每週重複的三個流程寫下來，例如競品檢查、廣告活動檢討或創意 brief，寫成簡單的逐步指示，並附上優良產出的範例。
  • 將品牌專屬的部分分開管理：語氣、禁用的宣稱、法律免責聲明、市場差異。正是這些部分讓你的產出屬於你。
  • 為它們做版本控管。流程改變，代理的行為就會改變。像對待程式碼一樣對待 skills，設定負責人並保留變更紀錄。
  • 安裝第三方 skills 前先審查安全性。skill 可能包含腳本。新的治理路線圖正因如此而提及安全指引；在它出現之前，請先讀過你要安裝的內容。
  • 衡量獨特性，而不只是速度。如果代理撰寫的內容開始看起來和競爭對手的一樣，代表你的脈絡太單薄了。

開放標準在你需要更換工具之前，並不令人興奮。當那一天到來，把專業知識寫成可攜格式的團隊，一週內就能遷移。其他團隊則得從頭開始。

常見問題

Agent Skill 是什麼？

根據 Anthropic 的說法，skill 是一個包含 SKILL.md 檔案的資料夾，用來教導 AI 代理執行特定任務或領域的工作，並附上該任務所需的任何腳本或參考資料。

現在由誰維護 Agent Skills 標準？

Anthropic 已將該標準、其名稱、標誌、GitHub 組織及 agentskills.io 網域捐贈給 Linux Foundation 旗下的 Agentic AI Foundation。來自 Anthropic、Google、OpenAI 及其他公司的工程師以個人身分維護它。

行銷人可以如何運用 Agent Skills？

把可重複的流程寫下來，例如 brief、競品檢視或廣告活動報告，並附上品牌規則與範例，讓不同工具中的 AI 代理都遵循團隊自己的方法，而不是通用的預設做法。
