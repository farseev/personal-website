Agent Skills 走向厂商中立：营销人员为何应当关注

Anthropic 将 Agent Skills 标准捐赠给了 Agentic AI Foundation。可移植、成文的专业知识，正是营销团队需要 AI 智能体具备的。

新闻：Anthropic 将 Agent Skills 开放标准捐赠给 Linux Foundation 旗下的 Agentic AI Foundation（2026 年 10 月 22 日）

作者：Aleks Farseev 教授2026 年 11 月 8 日阅读约 4 分钟

一些最重要的 AI 新闻，表面上看起来很枯燥。10 月 22 日，Anthropic 宣布将 Agent Skills 标准移交给 Linux Foundation 旗下的 Agentic AI Foundation。没有新模型，也没有新基准。但如果你在用 AI 智能体做营销，正是这类“管道工程”决定了你的专业知识能否始终属于你自己。

发生了什么

根据 Anthropic 的文章，skill 是“一个包含 SKILL.md 文件的文件夹，用于教会智能体某项具体任务或某个领域，并附带其所需的脚本或参考资料”。Anthropic 在开发 Claude Code 的过程中设计了这一格式，因为通用智能体往往缺乏真实业务任务所需的流程性知识。它于 2025 年 10 月推出 skills，并于 2025 年 12 月将 Agent Skills 作为开放标准发布。

采用规模相当可观。Anthropic 称已有 70 多个智能体平台集成了 Agent Skills，包括 ChatGPT、Cursor、GitHub Copilot 和 VS Code；已发布的 skills 达 100 万个，安装量接近 2.8 亿次。

如今，该标准本身、其名称与标志、GitHub 组织以及 agentskills.io 域名都将移交给 Agentic AI Foundation（AAIF）。AAIF 由 Anthropic 与 Block、OpenAI 共同创立，Anthropic 此前也已将 Model Context Protocol 捐赠给该基金会。来自 Anthropic、Google、OpenAI 及其他公司的工程师将以个人身份维护该标准。拟议的路线图包括版本化发布、正式的提案流程，以及面向编写和安装 skills 人员的安全指引。

为什么重要

我认识的每个营销团队，都拥有同一种隐性资产：他们做事的方式。怎么写简报；先看哪些竞争对手；对这个市场的这位客户而言，“符合品牌调性”究竟意味着什么。如今，这些大多存在于人们的脑子里，以及没人会读的幻灯片中。

Skill 是把这套流程写下来、让智能体可以照做的一种方式。而厂商中立的标准意味着，你只需写一次，就可以期待它在团队所用的各种工具中都能运行。这正是“基于平台构建”与“基于格式构建”的区别。格式比平台活得更久。

还有第二个不那么显眼的好处：skill 是可读的。你可以打开文件夹，看到智能体被要求做了什么。在“这是 AI 决定的”逐渐成为常见借口的领域里，一份纯文本流程虽小，却是实实在在的问责。

我的研究怎么看

我曾在 Forbes 撰文，讨论营销中从提示词与微调到 RAG 与 AI 智能体的进阶路径，以及AI 智能体在营销中的 18 种应用。我反复得出的规律是：智能体之所以失败，与其说是缺乏智能，不如说是缺乏上下文——也就是完成这项工作所需的具体数据和具体流程。

我们最新的论文让这一点更加具体。在SOMIN: Agentic AI for Automating Professional Visibility and Countering Content Homogenization（SIGIR 2026）中，我们描述了帮助专业人士撰写有辨识度的 LinkedIn 内容的检索增强智能体。核心思想是：智能体在写作之前应先检索真实的上下文数据，这样它的产出才能保持独特，而不会趋同于其他人的智能体所生成的千篇一律的文本。

Skills 是检索的流程性“孪生兄弟”。检索给智能体事实，skill 给它方法。两者都在对抗同质化，因为它们都把属于你的独特之处注入一个默认会滑向“互联网平均水平”的系统。如果每个品牌都用同一个智能体、同样的默认行为，每个品牌听起来都会一模一样。你的 skills，正是你的差异所在。

营销团队现在应该做什么

  • 把你每周都要重复的三项流程——例如竞品检查、广告活动复盘或创意简报——写成简明的分步说明，并附上优秀产出的示例。
  • 把品牌专属的部分单独存放：语气语调、禁用的宣传主张、法律免责声明、市场差异。正是这些部分，让你的产出成为你自己的。
  • 做好版本管理。流程一变，智能体的行为就会变。像对待代码一样对待 skills：指定负责人，保留变更记录。
  • 安装第三方 skills 之前先审查安全性。Skill 可以包含脚本。新的治理路线图正因如此提到了安全指引；在它出台之前，请先读懂你要安装的东西。
  • 不仅衡量速度，也要衡量辨识度。如果你的智能体写出的内容开始和竞争对手的相似，说明你的上下文太单薄了。

开放标准在你需要更换工具之前都不怎么令人兴奋。等到那一天，把专业知识以可移植格式写下来的团队一周就能完成迁移；其他团队则只能从头再来。

常见问题

什么是 Agent Skill？

根据 Anthropic 的说法，skill 是一个包含 SKILL.md 文件的文件夹，用于教会 AI 智能体某项具体任务或某个领域，并附带该任务所需的脚本或参考资料。

Agent Skills 标准现在由谁维护？

Anthropic 已将该标准及其名称、标志、GitHub 组织和 agentskills.io 域名捐赠给 Linux Foundation 旗下的 Agentic AI Foundation。来自 Anthropic、Google、OpenAI 及其他公司的工程师以个人身份对其进行维护。

营销人员可以如何使用 Agent Skills？

把可重复的流程（例如简报、竞品评估或广告活动报告）连同品牌规则与示例一起写下来，让不同工具中的 AI 智能体都遵循团队自己的方法，而不是通用的默认做法。
